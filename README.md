# PindiCafe & Restaurant — Website

A responsive, cinematic black-and-gold restaurant landing page made with **HTML, CSS, and vanilla JavaScript**.

## Files
- `index.html` — all page content and sections
- `style.css` — layout, colors, responsive styles, and CSS animations
- `script.js` — mobile menu, reveal-on-scroll, footer year, and cursor glow

## Run it
1. Extract this ZIP folder.
2. Open the `PindiCafe-Website` folder.
3. Double-click `index.html` to open it in your browser.
4. Recommended: use VS Code and the Live Server extension, then right-click `index.html` → **Open with Live Server**.

No build step, backend, or package installation is required.

## Important notes
- The page uses online Unsplash food/interior photos and Google Fonts, so an internet connection is needed to load those assets.
- Food photos in the Highlights section are illustrative examples, not confirmation that these dishes are on the restaurant's real menu.
- The provided listing says the restaurant is open 24 hours and has a 4.3 rating from 59 reviews. These details can change.
- Contact number and address are based on the information supplied for the project.
- WhatsApp contact uses `https://wa.me/923405246567`. Phone calls use `tel:+923405246567`.
- The Google Maps buttons open a search/directions result. Verify the exact pin with the owner before publishing.
- This is a static front-end website. It does not include a live ordering system, booking database, or payment checkout.

## Customize later
- Change text and sections in `index.html`.
- Change colors and layout in `style.css` (the main colors are at the top under `:root`).
- Replace the image URLs in `index.html` and `style.css` with restaurant-approved photos when available.
